## 二、项目背景与目标

水位数据是水利工程、防汛预警、水资源调度等领域的关键监测指标。水位传感器在实际运行中可能因设备故障、通信干扰、极端天气等原因产生异常读数，若不及时发现处理，可能导致误报警或漏报警。

本项目设计并实现了一套**基于LSTM自编码器（LSTM Autoencoder）的水位时间序列异常检测系统**，核心目标为：

1. 利用深度学习自动学习正常水位数据的时序模式和波动规律；
2. 通过重构误差量化数据点的异常程度；
3. 以统计阈值自动标记异常数据点；
4. 提供命令行和Web可视化两种交互方式，方便不同场景下的使用。

## 四、核心技术原理

### 3.1 LSTM自编码器

本系统采用**自编码器（Autoencoder）**架构进行异常检测。自编码器是一种无监督学习模型，由编码器（Encoder）和解码器（Decoder）两部分组成：

- **编码器**：将输入序列压缩为低维隐藏表示（瓶颈层）；
- **解码器**：从隐藏表示重建原始序列。

**核心假设**：在正常数据上训练的自编码器，对正常模式的输入能够准确重建，而对异常模式的输入重建效果较差。因此，**重构误差（Reconstruction Error）** 可以作为异常程度的度量指标。

### 3.2 模型结构

```
输入序列 (batch, 30, 1)
        │
        ▼
┌───────────────────┐
│  Encoder LSTM     │  双层LSTM, hidden_size=64
│  (2 layers)       │  dropout=0.1
└───────┬───────────┘
        │  取出最后一层的 hidden state
        ▼
┌───────────────────┐
│  Decoder LSTM     │  将hidden state重复展开为30步
│  (2 layers)       │  逐步重建序列
└───────┬───────────┘
        │
        ▼
┌───────────────────┐
│  Linear Layer     │  64 → 1，映射回原始维度
└───────┬───────────┘
        │
        ▼
重建序列 (batch, 30, 1)
```

### 3.3 异常检测流程

```
1. 加载原始水位数据
        │
2. 使用训练时保存的 MinMaxScaler 归一化到 [0, 1]
        │
3. 滑动窗口创建长度为 seq_len=30 的序列
        │
4. 模型逐序列推理，计算 逐点重构误差
   （取每个序列最后一步的误差作为该点的异常分数）
        │
5. 计算阈值 = mean(误差) + threshold_factor × std(误差)
        │
6. 标记异常：重构误差 > 阈值 → 异常
        │
7. 与真实标签对比，输出评估指标（精确率、召回率、F1）
```

**逐点误差策略说明**：不使用整段序列的平均MSE，而是只取序列**最后一步**的重构误差。这是因为单个异常值只占30步序列中的1步，全序列平均会严重稀释异常信号。

### 3.4 仅用正常数据训练

为确保模型对异常数据敏感，训练时采取以下策略：

1. **Scaler归一化仅拟合正常样本**：避免异常值拉偏归一化范围；
2. **训练序列排除含异常点的序列**：一条异常点会污染包含它的30条序列，全部剔除；
3. **验证集同样仅含正常序列**：确保早停判断基于正常模式的学习程度。

## 五、功能模块详解

### 4.1 数据模块（data_utils.py）

| 函数 | 功能 |
|---|---|
| `load_water_level_data()` | 加载CSV中指定列的水位数据 |
| `load_data_with_labels()` | 同时加载数据和异常标签 |
| `normalize_series()` | MinMaxScaler归一化到[0,1] |
| `create_sequences()` | 滑动窗口生成序列 |
| `prepare_data()` | 一站式数据准备（支持clean_only模式） |
| `save_scaler() / load_scaler()` | Scaler持久化存储与加载 |
| `generate_sample_water_data()` | 生成模拟水位数据（含日/周周期+噪声+异常） |

### 4.2 训练模块（train.py）

| 特性 | 说明 |
|---|---|
| 损失函数 | MSELoss（重建损失） |
| 优化器 | Adam (lr=1e-3) |
| 训练/验证集 | 80%/20% 随机划分 |
| 早停机制 | patience=10，保存最佳模型 |
| 模型保存 | PyTorch state_dict + Scaler pickle |
| 可视化 | 训练/验证损失曲线（中文标签） |

### 4.3 检测模块（detect.py）

| 特性 | 说明 |
|---|---|
| 异常阈值 | mean + factor × std |
| 逐点误差 | 序列最后步的逐点重构误差 |
| 评估指标 | 混淆矩阵、准确率、精确率、召回率、F1 |
| 可视化 | 双面板图（水位曲线+误差柱状图） |

### 4.4 Web交互界面（web_app.py）

基于 **Streamlit + Plotly** 构建，提供4个选项卡：

| 选项卡 | 功能 |
|---|---|
| 📥 数据输入 | CSV上传 / 手动输入 / 示例数据生成 |
| 📊 检测结果 | 交互式图表、指标卡片、评估报告、数据表、CSV下载 |
| 🏋️ 模型训练 | 界面内训练新模型，可调所有参数 |
| ℹ️ 关于 | 系统介绍、工作原理、技术栈 |

## 六、配置参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `seq_len` | 30 | 滑动窗口长度 |
| `hidden_size` | 64 | LSTM隐藏层大小 |
| `num_layers` | 2 | LSTM层数 |
| `dropout` | 0.1 | Dropout比率 |
| `batch_size` | 64 | 批次大小 |
| `lr` | 0.001 | 学习率 |
| `epochs` | 50 | 最大训练轮数 |
| `threshold_factor` | 1.5 | 异常阈值因子（越大检出越少） |
| `val_split` | 0.2 | 验证集比例 |
| `patience` | 10 | 早停耐心值（验证损失不降轮数） |

## 七、使用指南

### 6.1 环境安装

```bash
pip install -r requirements.txt
```

### 6.2 方式一：Web界面（推荐）

```bash
streamlit run web_app.py
```

浏览器访问 `http://localhost:8501`，在界面中：
1. 选择数据输入方式（上传/手动/生成示例）
2. 调整检测参数（阈值因子、序列长度）
3. 点击「开始异常检测」
4. 查看交互式结果图表和评估指标
5. 下载检测结果CSV

### 6.3 方式二：命令行一键运行

```bash
# 完整流程（生成数据→训练→检测）
python run.py

# 跳过数据生成
python run.py --skip-generate

# 跳过训练
python run.py --skip-train
```

### 6.4 方式三：分步运行

```bash
# 第一步：生成示例数据
python src/data_utils.py

# 第二步：训练模型
python src/train.py \
    --data-path data/water_level.csv \
    --model-path models/lstm_autoencoder.pth \
    --scaler-path models/scaler.pkl \
    --epochs 50

# 第三步：异常检测
python src/detect.py \
    --data-path data/water_level.csv \
    --model-path models/lstm_autoencoder.pth \
    --scaler-path models/scaler.pkl
```

## 八、实验结果

基于2000条模拟水位数据（含100个注入异常点，异常幅度6~8单位）的测试结果：

| 指标 | 数值 |
|---|---|
| 准确率（Accuracy） | 98.73% |
| 精确率（Precision） | 100.00% |
| 召回率（Recall） | 74.49% |
| F1分数（F1-Score） | 85.38% |
| 检出异常数 | 73 / 98 |
| 误报数 | 0 |

**结论**：系统在模拟数据上实现了零误报，成功的异常检出率为74.5%。漏检的异常点主要位于异常幅度较低的区间（约为正常波动的边界附近）。通过调节阈值因子可在精确率与召回率之间取得平衡。

## 十、改进方向

1. **模型架构升级**：引入Attention机制或Transformer架构，提升对长序列的建模能力；
2. **多特征输入**：融合降水量、流速、温度等多维监测数据；
3. **自适应阈值**：使用动态阈值替代固定统计阈值，适应不同时期的基线变化；
4. **在线学习**：支持增量学习，使模型能够适应水位模式的季节性漂移；
5. **预警推送**：检测到异常后自动发送通知（邮件/短信/Webhook）；
6. **GPU加速**：优化DataLoader和模型并行，提升大规模数据处理效率。
